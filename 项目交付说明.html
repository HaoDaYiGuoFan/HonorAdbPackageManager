核心机制

1 · 设备检测

启动检查 adb.exe → adb devices → 多设备弹窗选择 → getprop 读取 MagicOS 版本

2 · 包列表

pm list packages -f / -s / -3 / -d 四路合并 → dumpsys 并发解析（4 线程）

3 · 知识库匹配

命中：显示中文名/描述/风险；未命中：标记未知应用，操作前强制二次确认

4 · 分级操作

第三方=uninstall -k --user 0；系统=disable-user；核心=按钮灰化拦截

5 · 还原 / 备份

停用包 pm enable 一键还原；已卸载第三方提示需 APK；adb pull 备份到 Backup/序列号/

风险分级与操作映射

风险类型执行命令界面行为
安全 低风险第三方pm uninstall -k --user 0确认弹窗 + 勾选「我已知晓风险」
安全 低风险 高风险系统可停用pm disable-user --user 0确认弹窗；还原走 pm enable
禁止操作核心系统—按钮灰化 + 悬浮提示「禁用会导致设备异常」
未知应用知识库未收录按类型走卸载/停用高危红色弹窗 + 强制勾选确认

发行目录结构

  • HonorAdbPackageManager.exe — 主程序（自包含，目标机无需安装 .NET）
  • adb/ — adb.exe + AdbWinApi.dll + AdbWinUsbApi.dll（官方 platform-tools 37.0.1）
  • Data/HonorPackageDb.json — 内置知识库（可手改，或界面「导入外部知识库」合并）
  • Cache/icons/ — 图标缓存（按需从选中 APK 提取，可随时清空）
  • Backup/{序列号}/ — APK 备份
  • Logs/ — 导出的日志 TXT
